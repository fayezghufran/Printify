# 🖨️ Printify Website Replica  

This is a **frontend project** where I replicated the core design and functionality of the Printify website, adding my own unique touches. Built using **React.js**, **Vite**, and **Tailwind CSS**, the project showcases a dynamic and visually appealing user interface enhanced with **AOS (Animate On Scroll)** animations.

---

## ✨ Features  

- **Printify-Inspired Design**: Closely resembles the original Printify website with customizations.  
- **Smooth Animations**: Added engaging scroll-based animations using AOS for a modern and interactive experience.  
- **Responsive Layout**: Fully optimized for desktop, tablet, and mobile screens.  
- **Interactive UI Elements**: User-friendly components for seamless navigation.  

---

## 🛠️ Technologies Used  

- **React.js**: For building reusable and dynamic UI components.  
- **Vite**: For fast development and optimized builds.  
- **Tailwind CSS**: For efficient and responsive styling.  
- **AOS (Animate On Scroll)**: For scroll-triggered animations and effects.
